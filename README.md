# 🚗 Car Rental App

---

## 📌 Description

Car Rental App is a web application that allows users to browse a catalog of cars, filter them by various parameters, view detailed information about each car, book a rental through a booking form, and add cars you like to your favorites.

The project is built with a focus on clean UI, responsive design, and a smooth user experience.

---

## ✨ Features

- Browse a catalog of available cars
- Filter cars by brand, price, and mileage
- Load more cars with pagination
- View detailed information about each car
- Add cars to favorites
- Dedicated Favorites page with pagination
- Car booking form with submission handling
- Success notifications for user actions
- Error handling and 404 page for unknown routes
- Responsive and user-friendly UI

---

## 🧰 Tech Stack

- React (Hooks, Router)
- JavaScript (ES6+)
- Axios
- React Router DOM
- React Icons
- React Hot Toast
- CSS Modules
